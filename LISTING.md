# Browser extension store listing: Facet

**Name:** Facet: diamond size and report check

**Short description (132 chars max):**
See how big a diamond really is, on any listing. Scan the page or type a carat. Verify reports on the lab's own site.

**Detailed description:**
Carat is weight. What you see is millimeters. Facet turns any carat weight into the face-up
size it actually is, for the shape you are looking at, drawn against a 10 mm ruler, so a 1.5
carat oval on one site and a 1.5 carat round on another stop looking like the same thing.

Click "Scan this page" on any diamond listing and Facet finds the carat weight and shape in
the page text and shows the size. Or type them in. Nothing to sign up for, nothing stored,
nothing tracked. It runs only when you click it.

It also puts the three grading labs' official verification pages one click away (GIA, IGI,
GCAL), with the three checks that matter: confirm the report number on the lab's own site,
match the girdle inscription, match the measurements to the stone in front of you. Never
trust a screenshot or a seller's PDF.

For a text-layer PDF, the extension also opens Report Lens, a local-only report reader that
extracts the factual fields into one clean view. The file and report number stay in the browser.
If the shopper wants human help, Facet can prepare an email request with the selected shape,
carat, and a random request code. Nothing is sent unless the shopper sends that email.

The size math uses vetted anchors for typical proportions (a 1 carat round is about 6.5 mm)
scaled by the cube root of weight. It is education, not appraisal: always check the exact
millimeters on the stone's own report.

Made by Stienhardt, a New York City jeweler that sources certified Lab Grown Diamonds and
hand-sets and finishes rings in the city, by appointment. We built this because the same
question comes up in every appointment: "how big is that, really."

**Category:** Shopping. **Language:** English. **Privacy:** no user data collected.

**Permission justification:** `activeTab` and `scripting` are used only after the shopper clicks
"Scan this page." Facet reads visible listing text in that active tab to identify a carat weight
and supported shape. It does not retain or transmit the text.

**Store packages:** Use the package whose filename names the destination store. Each build has the
same functionality but carries a distinct public distribution label in deliberate Stienhardt
links and coded email requests. This makes store performance measurable without identifying the
shopper or collecting their browsing history.

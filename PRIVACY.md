# Facet privacy policy

Effective September 2, 2026.

Facet does not collect, store, sell, or transmit personal information or browsing history.

The browser extension runs only when the user opens it. Its optional page scan reads visible
text in the active tab to find a diamond shape and carat weight. That text stays in the browser.
Facet does not use a background process, analytics SDK, cookie, account, or remote code.

The bookmarklet follows the same rule. It reads the visible page locally and opens the public
Facet calculator with only the detected shape and carat weight. It does not send the source page
URL, seller name, page text, or report number.

The installed web app can appear as a share target on supported devices. The service worker reads
the title, text, and URL the user explicitly shares, extracts only a supported shape and carat
weight, and redirects to Facet with those two fields. The listing URL and shared text are not sent
to the Facet host, cached, stored, or included in a Stienhardt link.

Report Lens processes text-layer grading-report PDFs in the browser with a bundled copy of PDF.js.
The PDF, extracted text, and report number stay on the device. Report Lens opens a grading lab's
generic verification page but does not place the report number in that outbound URL. If a scanned
PDF has no selectable text, Facet reports that limitation instead of uploading the document for
remote OCR.

The Intent Bridge creates a random request code in the browser. A name, email address, or report
number is not attached to that code. Facet sends nothing when the code is created. The shopper can
choose to open a prefilled message to jgalperin@stienhardt.com containing the code, shape, carat,
measurements, and selected report fields. The message leaves the device only if the shopper sends
it through their own email service.

Links from Facet to stienhardt.com include campaign parameters so Stienhardt can measure visits
and orders attributed to the tool. Those parameters contain the selected shape and carat weight,
not identity or browsing history. Stienhardt's own privacy policy applies after a user chooses to
visit stienhardt.com.

Questions: jgalperin@stienhardt.com

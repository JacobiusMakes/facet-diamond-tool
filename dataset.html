The millimeters behind carat weight, in a file you can actually use.

Eighty-four approximate face-up size rows for round, oval, emerald, and Dutch Marquise diamonds. Download them, cite them, build with them, or inspect every value here.

Download CSV Download JSON View source and citation

What it is

A reproducible estimate generated at 0.1 carat intervals from 1.0 through 3.0 carats.

How it works

Each one-carat length and width anchor is scaled by the cube root of carat weight.

What it is not

It is not a survey of individual stones or a substitute for grading-report measurements.

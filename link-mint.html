Facet Link Mint

A useful link you can actually measure.

Make a Facet size-check link for a newsletter, article, PDF, social bio, or any platform that removes scripts. Attribution identifies the publication, never the reader.

Set the starting check

Use a publication or placement name that is already public. Do not put a person's name, email address, campaign recipient, or customer ID in the slug.

Copy the link

Open test link

No reader identifier. The link carries only the public publisher slug, supported shape, and carat weight. It sets no Facet cookie.

Works where scripts do not

Use it in Substack, Medium, email, a PDF, a QR code, or a normal hyperlink.

Intent survives

If a reader later opens matching inventory, the visit records publisher_link_<slug>, shape, and carat.

Private by design

No source article URL, recipient, report number, listing, seller, or price enters the link.

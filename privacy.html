Privacy policy

Effective September 2, 2026.

Facet does not collect, store, sell, or transmit personal information or browsing history.

Browser extension

The browser extension runs only when the user opens it. Its optional page scan reads visible text in the active tab to find a diamond shape and carat weight. That text stays in the browser. Facet does not use a background process, analytics SDK, cookie, account, or remote code.

Bookmarklet

The bookmarklet follows the same rule. It reads visible page text locally and opens the public Facet calculator with only the detected shape and carat weight. It does not send the source page URL, seller name, page text, or report number.

Same Stone

Same Stone stores saved candidates in local browser storage on the user's device. Seller name, listing URL, displayed price, grading lab, report number, measurements, and private notes are not uploaded to Facet or Stienhardt. The optional capture bookmarklet moves visible page text directly between the listing tab and the Same Stone tab inside the browser. Same Stone extracts candidate fields and discards the captured page text instead of storing it.

Exported CSV and JSON files are created locally. Clearing the vault or the browser's site data removes the locally stored candidates. A Stienhardt inventory link from Same Stone contains only shape, carat weight, and whether the local vault found a possible match.

Stone on Hand

Stone on Hand decodes the selected hand photo in the browser and draws the calibrated diamond footprint onto an on-device canvas. The photo and exported preview are not uploaded to Facet or Stienhardt. The tool does not use facial recognition, image analysis, analytics, an account, or remote storage.

A shared size-choice link contains only shape, carat weight, and via=share. If the user deliberately opens Stienhardt inventory, the attributed link contains only shape, carat weight, and the hand-preview surface.

Attributed links

Links from Facet to stienhardt.com include campaign parameters so Stienhardt can measure visits and orders attributed to the tool. Those parameters contain the selected shape and carat weight, not identity or browsing history. Stienhardt's own privacy policy applies after a user chooses to visit stienhardt.com.

Facet Publisher Kit

One tag. Your page. Measurable diamond intent.

Add the calculator to an article, guide, resource library, or storefront without an iframe or a JavaScript dependency. Styles stay isolated. Facet sets no cookies. Every inventory click carries the publisher, shape, and carat.

Install it anywhere

Replace your-publication with a short public slug. That slug becomes the placement dimension in attributed visits and orders.

1. Load the component
<script src="https://cdn.jsdelivr.net/gh/JacobiusMakes/facet-diamond-tool@v0.4.1/facet-widget.js"></script>
2. Place the calculator
<facet-diamond-size publisher="your-publication" shape="oval" carat="1.50" commerce="on"></facet-diamond-size>

Neutral mode

Set commerce="off" to remove all external links while keeping the calculator.

Platforms that remove scripts

Use Link Mint for newsletters, documents, social bios, and ordinary hyperlinks.

WordPress

Install the plugin ZIP, then add [facet_diamond_size] to any post, page, or Shortcode block. It defaults to neutral mode. The site hostname becomes the attribution slug automatically.

Private by construction

The component makes no background requests, sets no cookie, loads no font, and stores no customer data. Only a deliberate inventory click leaves the host page.

Attribution survives

The destination URL records web_component_<publisher>, normalized shape, and two-decimal carat weight for aggregate Shopify session and order reporting.

Publisher-controlled

Set the starting shape, carat, publisher slug, and light or dark theme with HTML attributes. The component emits a facet-change event when the selection changes.
